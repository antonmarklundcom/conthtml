# Editorial accounting design

The approved design uses paper white, Georgia headings, dark blue text, fine
dividers and small corner radii. WhatsApp actions use #25D366 with dark text;
the proposal form uses a blue submit button. Shared styles apply to all public
pages, including services, guides, tools, pricing and the English section.

The homepage keeps its existing H1 and metadata. Its copy now explains how
organized accounting, tax and payroll work lets owners focus on customers,
operations and growth. It describes the agreed scope and the information the
client provides without promising zero problems or guaranteed business growth.

The homepage reuses the consultation photo with responsive AVIF/WebP sources,
an illustrative caption and both people kept in the crop. No image credits
were spent. The office portrait remains available at its existing asset paths.

Useful ideas from the supplied Claude design: separate service-detail links,
clear responsibilities and written scope. The existing PHP lead form is kept;
the Claude export's demo form and support.js dependency are not deployed.

URL paths, redirects, indexed pages, canonical tags, titles, descriptions,
service H1s, schema and existing internal links are checked by the unchanged
SEO fixture. WhatsApp messages identify contador.com.py, the current page
and the requested service. CRM configuration is server-side and the local
tests use a mock CRM; those tests do not establish live CRM activation.

After review, merge the redesign PR into antonmarklundcom/conthtml main and
deploy main to Hostinger public_html using the existing Git integration.
No manual hosting configuration change is required for this design update.
