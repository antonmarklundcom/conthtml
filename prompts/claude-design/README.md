# Three standalone Claude Design prompts for Contador.com.py

Run each prompt in its own new Claude Design project. Copy the entire file; no prior conversation, extra briefing or attachment is required. Each requests exactly one complete desktop homepage above its mobile adaptation. The prompts are design artifacts only; they do not deploy a redesign.

| Prompt | Direction |
|---|---|
| [01 — Editorial accounting](01-editorial-accounting.md) | Serif headlines, paper background, precise navy details; recommended starting point. |
| [02 — Modern consultancy](02-modern-business-consultancy.md) | Sans serif, sharp grid, charcoal/white and cobalt details. |
| [03 — Warm professional](03-warm-professional-practice.md) | Cream, burgundy and existing conversation photography. |

Use the strongest model available within Claude Design; choose high effort if offered. All three prompts reuse verified reachable WebP URLs from the current site, exclude its playful illustrations, preserve the existing homepage H1/SEO routes and make no invented professional/team/client claims. No paid image generation is requested.

Production WhatsApp changes are implemented separately in PHP and the deadline tool script. CRM live delivery remains unverified: the four live pages inspected had no attribution script. A design prototype cannot activate a server-side CRM key.
